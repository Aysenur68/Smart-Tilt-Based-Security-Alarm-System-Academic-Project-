# Smart Tilt-Based Security Alarm System

## Overview

This project is an Arduino-based security alarm system designed and simulated in Tinkercad.

The system detects the state of a tilt sensor and activates different alarm modes depending on the sensor status.

## Features

- Tilt sensor detection
- Sequential LED lighting
- RGB LED status indication
- Siren alarm using an active buzzer
- Manual reset button
- LCD user instructions
- Developed and tested in Tinkercad

## Components

- Arduino UNO
- Tilt Sensor
- RGB LED
- LEDs
- Active Buzzer
- Push Button
- LCD Display

## Software

- Arduino IDE
- Tinkercad
